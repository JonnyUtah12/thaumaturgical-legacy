# Asset Provenance — TL-006

Every asset in this repository must have one of these provenances:

| Category | Policy |
| --- | --- |
| Textures / models | Authored for this project (original pixel art by/for this project). No texture extracted from Thaumcraft or Baubles JARs. |
| Sounds | Original or explicitly freely-licensed (record source + license here). None from original JARs. |
| Lang / text | Written for this project. Item names describe our own content; no copied lang strings. |
| Code | 100% independent implementation (see REVERSE_ENGINEERING_POLICY.md). |
| Data (recipes, research JSON) | Authored for this project; gameplay numbers may be *informed* by documented original behavior but are our own values. |

## Register

Format: `path | origin | author | license`.

- `assets/thaumaturgicallegacy/textures/item/thaumic_wand.png` | original 16x16 placeholder generated by project tooling (pure-Python PNG writer) | Thaumaturgical Legacy (TL-009) | CC0-1.0
- `assets/thaumaturgicallegacy/textures/block/vis_tap.png` | original 16x16 placeholder generated by project tooling (pure-Python PNG writer) | Thaumaturgical Legacy (TL-009) | CC0-1.0
- `assets/thaumaturgicallegacy/textures/item/vis_amulet.png` | original 16x16 placeholder generated by project tooling (pure-Python PNG writer) | Thaumaturgical Legacy (TL-019) | CC0-1.0
- `assets/thaumaturgicallegacy/textures/slot/charm.png` | original 16x16 slot icon generated by project tooling (pure-Python PNG writer) | Thaumaturgical Legacy (TL-019) | CC0-1.0
- `src/main/resources/data/thaumaturgicallegacy/structure/empty.nbt` | copied byte-for-byte from the Mojang 1.21.1 client jar (`data/minecraft/structure/bastion/mobs/empty.nbt`, zero-size structure used as the gametest template) | Mojang | Minecraft EULA (vanilla game data, not Thaumcraft/Baubles IP)

All JSON data under `assets/` (models, blockstates, lang) and `data/`
(recipes, loot tables) is authored for this project by construction, per the
policy table above; it is not registered line-by-line.

## Explicit exclusions

- `Thaumcraft-1.7.10-4.2.3.5.jar` and `Baubles-1.7.10-1.0.1.10.jar` are never
  committed, bundled, or redistributed.
- Decompiled sources and extracted originals live only in the scratch directory
  outside this repository.
